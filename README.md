# Node Typescript Multiplication App

Instrucciones para correr y ejecutar los comandos

```
npx ts-node src/app.ts -b 9 -l 30 -s -n prueba.txt -d tablas
```

En donde:
- b: El numero que se multiplicará
- l: La cantidad de veces que se multiplicará (por defecto es 10)
- s: Establece si se va a mostrar el resultado en consola o no (por defecto está en false)
- n: El nombre del archivo exportado (por defecto es "table").
- d: Destino del archivo exportado a partir de la raiz del proyecto (por defecto es "outputs").
